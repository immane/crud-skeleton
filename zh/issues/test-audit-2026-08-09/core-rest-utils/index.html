    Core (Utils/Listener/Controller/Serializer) test audit (2026-08-09)¶

    Read-only audit of tests/Core/Utils, tests/Core/EventListener, tests/Core/Controller (root + System/), tests/Core/Serializer (+ Normalizer/), tests/Core/Exception, tests/Core/DependencyInjection. Cross-referenced against src/Core/* and the integration suite (tests/Integration/Core*ApiTest).

    Context: the 2026-08-09 coverage campaign (see docs/issues/coverage-2026-08-09/README.md) added many *CoverageTest / *ExtendedTest / *Coverage2Test files pushing line coverage to 99.46%. Several duplicate behavior already locked by pre-existing tests, or assert only that lines run. Skipped tests that document src/ bugs (Location L-2, Math M-1/M-2) are KEEP by policy.

    KEEP — bullet list¶

    Utils - ArrayCommonExtendedTest — real ExpressionLanguage filter/map/reduce behavior; the only place these helpers are validated. - ArrayCommonTest — small but includes testMergeMatchesCurrentLegacyBehavior, a genuine regression guard for the surprising array_merge($arrays) wrapping. - FixJSONTest — base coverage of getJSONType/fixJSON, both used in RestController and CreateApiViewMixin. - InflectExtendedTest — the substantive inflector rule table (irregular/uncountable/x-ch-sh/round-trip). Inflect::singularize is used in BaseServiceMutationTrait. - LocationTest — the only harness that can run Location (its php-curl-class dependency is absent); the skipped testGetAddressIsBrokenByStringMethodCall documents bug L-2. KEEP, incl. the skip. - MathCoverageTest — the three markTestSkipped cases document real bugs M-1 (mt_rand()/rand() one-arg crash on PHP 8.5) and M-2 (lcg_value() deprecation). - MathTest — real boundary assertions for random, abs, round, locationDistance, exact constant equality. - RsaClientTest — the only real RSA sign/verify/encrypt round-trip coverage; documents the MD5-signing and undefined-variable bugs (R-1/R-2). None skipped, all assert current behavior. - StringCaseExtendedTest — full dash→camel behavior matrix. - UUIDExtendedTest — v3/v4/v5 format bits, namespaces, determinism, whitespace rejection; UUID is used across every module. - UUIDTest::testV4ProducesValidUuid behavior is subsumed, but harmless until deletion of the file (see DELETE).

    EventListener - AccessLogListenerTest — thorough and unique: method whitelist, auth-path body hiding, truncation, binary/empty bodies, anon/username resolution. - ControllerListenerExtendedTest, ExceptionInterceptorExtendedTest, LocaleListenerTest — the substantive branch tables. - OpenApiEnricherListenerCoverageTest — the four early-return guards are not exercised by CoreOpenApiEnricherApiTest (which only hits the happy path). Note: testJsonContentWithoutPathsReturnsEarly and testJsonArrayContentWithoutPathsReturnsEarly hit the same !is_array($spec) || !isset($spec['paths']) guard — collapse those two.

    控制器 - RestControllerTest + RestControllerExtendedTest — 信封形状，@display（复杂/减少/表达式），@expands，分页切片，204。 - RestControllerCoverage2Test — 独特的错误/边缘分支（resolveService、扩展链移位、静默吸气剂/表达式吞咽）。四个依赖项获取器异常测试（getRequestStack/getSerializer/getTranslator/getService）是薄的实现细节——在合并后考虑。 - RestControllerPaginationIntegrationTest — 仅测试通过真正的 QueryBuilder + DoctrinePaginator 驱动 pagination()。 KEEP（不要与数据库引导测试并行）。 - EntityControllerExtendedTest、RouterControllerTest — 修剪重复项后保留。 - CoreExtensionTest / ConfigurationTest — 验证services.yaml/Configuration中的DI接线；真正有用的合同测试。

    序列化器/异常/DI - FlatNormalizerCoverageTest - 独特的分支（装饰失败回退，__metadata减少，JSON字符串解码 - 记录JSON字符串损坏错误，覆盖报告中的错误11），序列化器/规范化器转发。 - Normalizer/CircularReferenceHandlerTest — 保留只是因为它仍然记录了可能被未来连线引用的类的契约；请注意，该类今天是孤立类（src//config/ 中没有任何内容引用 App\Core\Serializer\Normalizer\CircularReferenceHandler）。 - MessageHttpExceptionExtendedTest — 保留为规范文件。 - Serializer/CircularReferenceHandlerTest — keep（这是实际连接在config/packages/serializer.yaml中的处理程序）。

    验证步骤¶

    每次删除后运行（每个 TEST_STRATEGY 的 PHP 8.4+ 运行时）：

    /opt/homebrew/opt/php@8.5/bin/php ./vendor/bin/phpunit tests/Core/Utils tests/Core/EventListener tests/Core/Controller tests/Core/Serializer tests/Core/Exception tests/Core/DependencyInjection

    然后是全门：

    /opt/homebrew/opt/php@8.5/bin/php ./vendor/bin/phpunit
composer phpstan
composer rector:types:check

    覆盖范围警告（批量删除之前很重要）：

    • 安全删除（没有覆盖率回归，因为重复项会覆盖行）：所有 2 DUPLICATE 行（UUID v4c、Inflect、FixJSON、RestController 204/post/reduce/expr、EntityController斜杠/assoc、MessageHttpException、LocaleListener Missing-header、ControllerListener、ExceptionInterceptor）。
    • 覆盖范围敏感的删除 — 删除这些会降低仅这些测试所触及的线路的覆盖范围，并且 90% 的线路门可能会触发：
    • SerializerContextFactoryTest — SerializerContextFactory仅被services.yaml +此测试引用；删除它会发现该类。
    • FilterDateTimeTest — FilterDateTime::get() 仅在此处执行。
    • Dead utils（Math、StringCase、Location、RsaClient、Utils\ArrayCollection、Serializer\Normalizer\CircularReferenceHandler、ObjectCallback）除了测试之外从任何地方的 src/ 引用。仅在 src/ 清理的同时进行修剪（添加 @codeCoverageIgnore 或删除死类），或者在维护者签字后接受覆盖范围下降。
    • 根据 FlatNormalizerCoverageTest::testSetSerializerForwardsAsNormalizerToNormalizerAwareDecorated / testSetNormalizerForwardsToNormalizerAwareDecorated 验证两个 FlatNormalizerExtendedTest assertTrue(true) 删除（它们断言实际的转发合同并保持 setSerializer/setNormalizer 被覆盖）。
    • 不要与其他数据库引导集成测试并行运行RestControllerPaginationIntegrationTest（var/test.db模式拆卸竞赛）。
    • 断言已记录的 src/ 错误（位置 L-2、Math M-1/M-2、OpenApi BUG-7）的跳过测试必须保留 — 它们是有意保留的。
