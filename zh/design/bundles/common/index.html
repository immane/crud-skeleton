    通用捆绑设计¶

    通用捆绑包 (src/Common/) 是 CMS（内容管理系统）模块。它提供 标准内容实体（类别、标签、内容、评论、页面、媒体、设置） 公共只读 API 和管理 CRUD 端点。

    1. 概述¶

    Common 是一个通用 CMS 模块，具有 7 种实体类型，用于构建内容驱动的应用程序。它遵循标准模块契约：实体 -> 存储库 -> 服务 -> 控制器（应用程序 + 管理）。

    1.1 实体¶

    实体 表 目的
    Category common_category 层次类别（自引用树）
    Tag common_tag 平面标签/吊牌系统
    Content common_content 带有类别+标签的类似文章的内容
    Comment common_comment 对任何实体的多态注释
    Page common_page 独立页面（关于、条款等）
    Media common_media 文件元数据（文件名、路径、mime、大小）
    Setting common_setting 键值配置存储

    3. 实体关系¶

    Category (self-ref: parent -> children)
  |
  +-- 1:N -> Content (category_id FK)

Tag
  |
  +-- M:N -> Content (common_content_tag join table)

Comment (self-ref: parent -> replies)
  |
  +-- M:1 -> User (author)
  +-- Polymorphic: entityType + entityId -> any entity

Page       (standalone, no relations)

Media      (standalone, file metadata)

Setting    (standalone, key-value)

    4. 实体设计¶

    4.1 类别——层次树¶

    • 自引用：parent (ManyToOne) + children (OneToMany)
    • 独特的 slug 用于 URL 友好的引用
    • sortOrder 用于手动订购
    • enabled 软发布布尔值
    • 应用程序控制器过滤到 enabled = true

    4.2 内容——文章/帖子¶

    • title + body（文本）
    • 属于一个category
    • 多对多 tags
    • 自定义存储库方法：findLatest($limit)、findById($id)

    4.3 标签——平面标签¶

    • name + 独特的slug + color

    4.4 注释——多态¶

    • entityType (FQCN) + entityId -- 可以评论任何实体
    • 线程回复的自引用 parent
    • status 用于审核（待定/批准/拒绝）
    • author 对用户来说是多对一的

    4.5 页面 -- 独立内容¶

    • title、slug、body（文本）
    • SEO 字段：metaTitle、metaDescription
    • status + publishedAt 用于调度

    4.6 媒体——文件元数据¶

    • filename、originalFilename、mimeType、size、path
    • 显示字段：alt、title
    • 维度字段：width、height

    4.7 设置--键值存储¶

    • 独特的key、value、type、groupName
    • UI 元数据：label、description、sortOrder

    5.2 管理（管理员 CRUD、ROLE_ADMIN）¶

    所有 7 个实体都有完整的 CRUD： - GET /api/v1/manage/{resource} - GET /api/v1/manage/{resource}/{id} - POST /api/v1/manage/{resource} - PUT /api/v1/manage/{resource}/{id} - DELETE /api/v1/manage/{resource}/{id} - POST /api/v1/manage/{resource}/batch-update（与@mode=mixed）

    5.3 应用程序控制器 commonFilter() 覆盖¶

    每个应用程序控制器的公共访问范围：

    控制器 通用过滤器（）
    类别控制器 ['enabled' => true]
    页面控制器 可以按状态过滤
    其他 默认（无过滤器）

    6. 服务架构¶

    所有服务都扩展 BaseService + 实现其 *ServiceInterface：

    class CategoryService extends BaseService implements CategoryServiceInterface
{
    public function __construct(ContainerInterface $container, ...)
    {
        parent::__construct($container, Category::class, ...);
    }
}

    服务接口全部扩展BaseServiceInterface（空——默认情况下没有自定义方法）。

    7. 安全¶

    层 机制
    应用程序端点 无需身份验证（只读公共访问）
    管理端点 #[IsGranted('ROLE_ADMIN')] 上课
    评论作者 commonFilter() 范围（可选）

    8.ContentRepository接口¶

    ContentRepository 是唯一具有显式接口的存储库：

    interface ContentRepositoryInterface
{
    public function findLatest(int $limit): array;
    public function findById(int $id): ?Content;
}

    这允许其他模块使用内容而不依赖于具体的存储库。

    9. 数据库迁移¶

    版本：Version20250516000000

    创建所有 7 个表 + M:N 连接表 common_content_tag。将 category_id FK 添加到预先存在的 content 表（从 content 重命名为 common_content）。
